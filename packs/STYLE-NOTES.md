## What We Borrow (Kai Titles)

### Caps rhythm & Title Case
- Default to **Title Case** on public packaging lines (Discord headers, Key Updates hooks, asset type).
- Drop **ALL-CAPS ENERGY WORDS** sparingly for stakes: `FULL STREAM`, `INSANE`, `WILDEST`, `FIRST TIME`, `NOW`.

## What We Borrow (Kinse Thumbnail / Type Energy)

Kinse = Kai Cenat Live channel manager / thumbnail designer (YT Jobs); American self-taught GD (solo.to). Style cues for **Clip launch art**:

1. **Readable big type first** — 2–5 words max on logo/banner; feed-size legible.
2. **High contrast hierarchy** — subject/type pops off dark or flat field; one focal read.
3. **Cutout / glow edge energy** — silhouettes and icons separated with rim light / outline (not muddy blends).
4. **Clickbait background craft without clutter** — saturated color blocks, gradients, shards/spark — supporting, not competing with type.
5. **One prop that explains the video** — gavel = regulation; case = manhunt; red-helmet mystery = OP (person, not AI).
6. **Title ↔ thumbnail split** — title carries the event; art carries the tension / icon. Don’t duplicate every word.
7. **Saturation + Lightroom punch** — richer reds/cyans/silvers; avoid washed gray midtones.
8. **No face theft / no trademark theft** — original icons + Clip campaign names only.

## Thumbnail Hierarchy (Logo 1:1 · Banner 16:9)

```
┌─────────────────────────────────────┐
│  SMALL TAG (CLIP / campaign lane)   │  ← optional, tiny
│                                     │
│     GIANT TITLE (2–4 words)         │  ← primary read
│     short subline / stakes          │  ← secondary
│                                     │
│   [icon / prop / silhouette]        │  ← explains without essay
└─────────────────────────────────────┘
```

- **Logo (1:1):** icon + 1–2 word brand lockup; works as Discord avatar / campaign tile.
- **Banner (16:9):** same lockup scaled wide; room for subline + one prop; YouTube-editor feed energy.
- Prefer **Passion One / Kanit Black / Barlow Black / condensed ExtraBold** vibe — thick, loud, short.
